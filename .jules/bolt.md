## 2024-05-30 - Global Connection Pool Optimization in ai_logic.py
**Learning:** Re-patching global module-level mocks (like `_api_session.post`) across test suites requires `patch.object` instead of string-based `patch`. Additionally, refactoring test files to fix framework compatibility issues (e.g., `pytest` to `unittest`) is an anti-pattern that violates scope and introduces regressions (like missing `self` parameters).
**Action:** When creating global connection pools for module-level API calls, only update the necessary decorators (`patch.object(module._api_session, 'post')`) in the associated tests. Avoid out-of-scope test framework migrations. Always clean up temporary script files used for search-and-replace.
